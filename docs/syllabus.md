# 具身起源 · 课程大纲（16 章 × 8 关 = 128 关）

> 这是关卡清单的上游：每章主题、每关一个概念、"看起来对但会失败"的直觉。[levels.md](levels.md) 之后由本文件重建。设计总纲见 [design.md](design.md)，结构规则见 [圣经 §3](../../oo_kit/docs/trilogy-bible.md)。
> 一门两学期的机器人学 / 控制入门课：感知与驱动 → 反馈 → PID → 机械臂 → 移动机器人 → 规划 → 平衡 → 步态 → 估计 → 定位建图 → 现实差距 → 系统整合。

## 约定

- 关号 `章-序`，每章 8 关：1–3 谜，4 障，5–6 谜，7 障，8 托。每章 5 谜 / 2 障 / 1 托；故障关穿插在它要检验的概念之后。
- 类：**谜** 解谜 · **障** 故障（先指证，再修）· **托** 委托（自由工坊，章末）。
- 状态：✓ 48 个旧 id（id、机制、判分沿用旧规格，只改章号与关号；代码里按 id 只找到 18 个，多数仍是占位 stub，其余尚未实现）· N 新关。48 个旧 id 全部保留，因此多数章保留 2–4 个旧关，再补 4–7 个新关。
- 概念 ≤ 25 字；错的直觉 ≤ 20 字，是一个"看起来对、会失败"的做法，失败诊断必须能解释它。每关只讲一个概念。
- 指证列只有障关填写：示波器上的时间点 + 一路信号（圣经 §4.3），正确区间由核心层计算。
- 前置：同章按关号顺序；跨章按章号顺序；每章开头的"前置"一行写它依赖的概念。
